## 📖 About

This is an **AutoHotkey macro** that automates a rune farming method in **Elden Ring**. It runs the farm at the **Palace Approach Ledge-Road** in **Mohgwyn Palace**, using the **big bird** on the ledge as the rune source. Set it up, start the macro, and let it farm.

---

##  Requirements

| Item | Details |
|------|---------|
|  **Long Bow** | Must have the **Rain of Arrows** Ash of War equipped |
|  **Arrow's Reach Talisman** | Required for the farm to work |
| **Golden Scarab** *(recommended)* | Increases the runes you gain |
|  **AutoHotkey** | Needed to run the macro |

---

## ⚙️ Game Settings

**Resolution:** `1920x1080` in **Windowed** mode

**Required keybinds:**

| Action | Key |
|--------|-----|
| Camera Up | `I` |
| Camera Down | `K` |
| Camera Left | `J` |
| Camera Right | `L` |
| Attack | `P` |
| Strong Attack | `Y` |
| Skill | `Ctrl` |
| Map | `G` |

> ⚠️ The macro relies on these exact settings. If anything differs, it won't work properly.

---

##  How to Use

1. Install **[AutoHotkey](https://www.autohotkey.com/)**
2. Download this repository
3. Set up your game with the settings and keybinds above
4. Equip the **Long Bow** (with Rain of Arrows) and the **Arrow's Reach Talisman**
5. Go to the **Palace Approach Ledge-Road Grace** in Mohgwyn Palace
6. Run the macro script with **F9** and start farming
